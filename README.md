# Registro de Trabajo

## Probar en ordenador
1. Descomprime la carpeta.
2. Haz doble clic en `index.html`.
3. Introduce tu Gmail, proyecto y tarea.
4. Pulsa COMENZAR y después TERMINAR.
5. Pulsa CONFIRMAR Y ENVIAR. Se abrirá Gmail web con el correo ya preparado para enviarlo a tu propio Gmail.

Si Gmail no tiene la sesión iniciada en el navegador, te pedirá iniciar sesión.

## Móvil
Cuando la app se publique en una web HTTPS gratuita (por ejemplo GitHub Pages), podrás añadirla a la pantalla de inicio y usarla como app.
